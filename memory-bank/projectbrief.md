# Project Brief: GeekUninstallerJules

## Overview
GeekUninstallerJules is a high-fidelity clone of the popular Windows uninstaller, GeekUninstaller. The project aims to replicate the core functionality and user interface of the original application using modern cross-platform technologies (Flutter).

## Goals
- Replicate the GeekUninstaller UI with high fidelity.
- Provide a clean and efficient application management interface.
- Implement simulated "Clean Removal" and "Force Removal" features.
- Ensure the application is fast, lightweight, and easy to use.

## Core Features
- **Application List**: A detailed table showing installed applications, their sizes, and installation dates.
- **Search/Filter**: Instant search to quickly find specific programs.
- **Uninstallation Logic**: Simulated standard and force uninstallation with leftover scanning.
- **UI/UX**: Replicate the minimalist and functional design of GeekUninstaller, including highlighting recent items.
- **Store Apps**: Switch between desktop applications and Windows Store apps (simulated).

## Success Criteria
- High-fidelity UI that closely resembles GeekUninstaller.
- Functional application list with search and sorting.
- Simulated uninstallation workflows that provide user feedback.
- Clean and maintainable codebase.
