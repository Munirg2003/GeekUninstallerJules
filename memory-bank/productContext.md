# Product Context: GeekUninstallerJules

## Why this project?
Standard uninstallers often leave behind junk files, empty folders, and registry entries. GeekUninstaller solved this by providing a simple, fast, and thorough uninstallation experience. This clone aims to bring that experience to a modern, cross-platform framework while maintaining the "geeky" efficiency of the original.

## Problems Solved
- **Incomplete Uninstalls**: Replicates the "Clean Removal" concept by scanning for leftovers.
- **Broken Programs**: Replicates the "Force Removal" feature for programs that cannot be uninstalled normally.
- **Bloated UI**: Maintains a minimalist, single-window interface for maximum productivity.
- **Finding Apps**: Provides instant, type-to-search functionality.

## Target Audience
- Users who value system cleanliness and efficiency.
- Developers looking for a high-fidelity UI clone example.
- Anyone who prefers the classic GeekUninstaller interface but wants a modern implementation.

## User Experience
- The user is greeted with a clean list of all installed programs.
- Programs installed since the last run are highlighted.
- Real-time searching allows for immediate results.
- Uninstallation is triggered with a single click or right-click, followed by a simulated "deep scan" for leftovers.
